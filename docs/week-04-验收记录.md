# 第 4 周验收记录：用自然语言查询与请求采集

- 日期：2026-09-28
- 环境：ESP32-S3-EYE 真板（ESP-IDF 固件）+ 服务端 8080（计划任务常驻）+ 新增 /api/ask 与「语言助手」网页分页
- 模型口径：**产品运行时语言接口**与开发助手分离；本周未训练任何模型。
  默认使用确定性 rule 基线；LLM 适配槽仅从服务端环境变量读取
  （EYE_LLM_BASE_URL / EYE_LLM_API_KEY / EYE_LLM_MODEL），密钥不入库、不下发板端；
  语言服务不可达时自动回退 rule 基线并在响应中标注 fallback=true。

## 一、受限工具（本周核心约束）

| 工具 | 行为 | 边界 |
|---|---|---|
| query_latest | 只读库存记录（readRecords），返回来源/采集时间/接收时间/数据年龄/stale | 不触发任何采集；无该传感源记录时说明不足，不伪造 |
| request_collect | 复用第 2 周 request_id 闭环，等待 completed/timeout 后回复 | 超时明确说「本次没有收到新观测」，不以旧值冒充；超时 ≠ 硬件故障 |

越界与范围校验：索要坐标/位置/预测 → 拒答并说明无对应传感源；
未知设备 → 按已知设备范围拒答；歧义输入 → 反问二选一，不擅自执行任何工具。

## 三、真板当堂验证（/api/ask 直连运行中服务端）

| 话术 | 意图/工具 | 证据摘要 |
|---|---|---|
| 查看上次数据 | query / query_latest | 来自 S3EYE-GROUP01 seq 1857，三轴真实值 + 采集/接收时间，stale=false |
| 重新采集一次 | collect / request_collect | completed，request_id=req-20260928-144251-0001，新观测 seq 2122 |
| 估计一下设备现在的位置 | refuse | 「本系统没有定位传感源，不能生成或估计坐标/位置」 |
| 帮我弄一下数据 | clarify | 反问二选一：查看已保存记录 / 请求新采集 |

对照课程当堂验证：同一旧数据下「查看上次数据」保留旧时间（C6/stale 语义）；
「重新采集」等待对应新结果（C2/真板 spot-check）；无位置来源时说明不足、不生成坐标（C4）。

## 一、本周问题

学生借助智能体，怎样把开发板的一项真实传感数据采集出来，送到自己的 VPS/Web 平台并验证？

## 二、实现链路

板端读取 QMA6100P 加速度计（I2C 0x12，SDA=GPIO4，SCL=GPIO5）
→ Wi-Fi 联网并 SNTP 对时
→ 每 1 秒采集一次（每次 8 次硬件采样取平均）
→ HTTP POST /api/observations
→ 服务端校验、幂等去重后落盘
→ Web 页面每秒读取 /api/stats 与 /api/health 展示

## 五、本周修过的三个真实缺陷（排错记录）

1. **串口无输出**：板卡定义 ARDUINO_USB_CDC_ON_BOOT 初值 0，导致板端日志走 UART0，而 COM4 是原生 USB 串口。改为 1 后日志可读。
2. **合矢量只有 0.236 g**（静止应约 1 g）：原始值解析用算术右移 4 位，把 12 位值又缩小 4 倍。依据乐鑫官方驱动 esp-bsp/components/qma6100p 改为 (int16_t)((HIGH << 8) + LOW) / 4，修正后 |a| = 0.95 g。
3. **每条观测重复入库 3 次且板端误报失败**：板端未取回响应体即结束请求，POST 返回负值被判定失败并重试。改为显式读空响应体再收连接；服务端同时加入基于 record_id 的幂等去重。

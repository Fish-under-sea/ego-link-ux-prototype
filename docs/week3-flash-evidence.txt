【关键结论】
  1. LED   —— GPIO[3] 报告 "OpenDrain: 1"，即开漏模式已正确生效。
               官方文档要求必须开漏，否则拉高会烧 LED；本固件遵守。
  2. LCD   —— ST7789 初始化成功（240x240，SPI3）。GPIO[48] 为背光，已输出高电平点亮。
  3. 按键  —— ADC 校准成功：空闲读数 4095（接近 12bit 满量程，符合"无按键被上拉"的预期），
               按下判定阈值 = 4095 - 500 = 3595。
  4. IMU   —— QMA7981 初始化成功（±2g / 14bit），数据帧 seq 连续递增。
  5. 版本  —— App version 与 Git 提交 fe028d8 一致，确认板内运行的就是本次代码。

【说明】
  WiFi 仍为占位符 YOUR_WIFI_SSID（用户既有设定：本机无 WiFi 网卡，走 USB 串口），

## 二、物理反馈链路（与已烧录构建同源）

- LED：GPIO3，**开漏输出**（firmware/s3eye_imu_idf/main/main.c:487-503，GPIO_MODE_OUTPUT_OD；注释明确「拉高会烧 LED」）。
- LCD 中文状态字：lcd_draw_zh / lcd_draw_ascii（main.c:579 / 599 / 647）。
- 硬约束（main.c:481-484）：「没有收到 viewer_ack 之前，板端绝不显示『对方已收到』」。
- 按键：ADC1_CH0（GPIO1）电阻分压，6 功能键 + BOOT；本地反馈先于上报执行，网络失败不影响 LED/LCD。
